# 视频输入功能 — 实现方案与代码结构

## 一、设计原则

1. **零侵入现有管道**：Video模块是Pipeline的**前置预处理器**，输出仍是一组图像文件，不触碰 `pipeline.py` 任何一行
2. **后端切片 + 智能筛选**：视频解码和帧提取在后端完成，前端只负责上传视频文件
3. **可插拔**：`video_processor/` 作为独立子包，不依赖 Pipeline 内部逻辑，未来可独立维护

### 3.2 `hybridmvs/video_processor/extractor.py` — 帧提取器

```python
"""
Frame extractor: reads a video file and outputs individual frames.
"""

import os
import cv2
import logging

logger = logging.getLogger(__name__)


class VideoFrameExtractor:
    """
    Extract frames from a video file using OpenCV VideoCapture.

    Supports three extraction strategies:
      - "fixed_interval":  extract every N frames
      - "target_count":    extract exactly N frames evenly spaced
      - "adaptive":        extract based on motion detection (future)
    """

    def __init__(self, strategy: str = "target_count"):
        self.strategy = strategy

    def extract(
        self,
        video_path: str,
        output_dir: str,
        target_frames: int = 30,
        min_interval_frames: int = 3,
    ) -> list[dict]:
        """
        Extract frames from video.

        Args:
            video_path:    Path to the video file (mp4/mov/avi).
            output_dir:    Directory to save extracted frame images.
            target_frames: Target number of frames to extract.
            min_interval_frames: Minimum frame interval between extractions.

        Returns:
            List of dicts: [{"path": "...", "frame_idx": N, "timestamp_sec": T}, ...]
        """
```

**核心逻辑（`target_count` 策略）**：

```
1. cap = cv2.VideoCapture(video_path)
2. 读取视频元信息：
   - total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
   - fps = cap.get(cv2.CAP_PROP_FPS)
   - duration = total_frames / fps
3. 计算采样间隔：
   - interval = max(min_interval_frames, total_frames // target_frames)
4. 循环采样：
   for i in range(target_frames):
       cap.set(cv2.CAP_PROP_POS_FRAMES, i * interval)
       ret, frame = cap.read()
       if not ret: break
       保存为 JPEG 质量95（平衡质量与文件大小）
       记录 frame_idx, timestamp_sec
5. cap.release()
6. 返回帧信息列表
```

**为什么默认用 JPEG 而非 PNG**：
- 视频帧本身有压缩，PNG无损保存没有额外收益
- JPEG 质量95 文件体积是PNG的1/8，对COLMAP特征提取无影响

**边界处理**：
- 视频总帧数 < target_frames → 全取所有帧
- 视频总帧数极多（如10分钟视频） → 按target_frames均分，interval可能会很大，前端应提示用户控制视频长度

### 3.3 `hybridmvs/video_processor/selector.py` — 帧筛选器

```python
"""
Frame selector: filters extracted frames by quality and redundancy.
"""

import cv2
import numpy as np
import logging

logger = logging.getLogger(__name__)


class FrameSelector:
    """
    Filter a list of frame candidates to keep only high-quality,
    non-redundant frames suitable for SfM reconstruction.
    """

    def __init__(
        self,
        blur_threshold: float = 100.0,       # Laplacian variance threshold
        similarity_threshold: float = 0.92,   # histogram correlation threshold
        min_interval_seconds: float = 0.3,    # minimum time gap between selected frames
    ):
        self.blur_threshold = blur_threshold
        self.similarity_threshold = similarity_threshold
        self.min_interval_seconds = min_interval_seconds

    def select(self, frame_infos: list[dict]) -> list[dict]:
        """
        Filter frames through a 3-stage pipeline.

        Stage 1: Blur detection  (discard motion-blurred / out-of-focus frames)
        Stage 2: Redundancy removal (discard near-duplicate adjacent frames)
        Stage 3: Minimum interval enforcement

        Returns filtered list of frame_infos.
        """
```

**三阶段筛选详解**：

```
阶段1 — 模糊检测
──────────────────
  对每帧计算 Laplacian 方差:
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    lap_var = cv2.Laplacian(gray, cv2.CV_64F).var()
  
  判断:
    lap_var >= blur_threshold → 保留（清晰）
    lap_var <  blur_threshold → 丢弃（模糊/失焦）
  
  阈值经验值:
    100   — 较严格，适合高质量手机视频
    50    — 较宽松，保留更多帧

阶段2 — 冗余去除（基于相邻帧直方图相似度）
─────────────────────────────────────────────
  对阶段1保留的帧，逐对比相邻帧相似度:
    hist_a = cv2.calcHist([frame_a], [0,1,2], None, [64,64,64], [0,256]*3)
    hist_b = cv2.calcHist([frame_b], [0,1,2], None, [64,64,64], [0,256]*3)
    cv2.normalize(hist_a, hist_a)
    cv2.normalize(hist_b, hist_b)
    similarity = cv2.compareHist(hist_a, hist_b, cv2.HISTCMP_CORREL)
  
  判断:
    similarity < similarity_threshold → 保留（视角变化足够）
    similarity >= similarity_threshold → 丢弃（几乎相同的视角）
  
  对视频而言这是关键：相邻帧通常几乎一模一样，必须去重

阶段3 — 最小间隔强制
─────────────────────
  若筛选后剩余帧仍 > target数量:
    进一步按时间间隔(min_interval_seconds)均匀采样
  若筛选后帧 < 15张（太少无法重建）:
    降级处理：降低blur_threshold和similarity_threshold，重新筛选
  若降级后仍不足:
    返回警告，建议用户重新拍摄
```

**返回数据**：

```python
返回格式与 extractor.extract() 相同:
[
    {"path": "output_dir/frame_00012.jpg", "frame_idx": 12,  "timestamp_sec": 0.40},
    {"path": "output_dir/frame_00045.jpg", "frame_idx": 45,  "timestamp_sec": 1.50},
    ...
]
```

### 3.4 `hybridmvs/video_processor/preprocessor.py` — 编排器

```python
"""
Video preprocessor: orchestrates extraction and selection.
"""

import os
import tempfile
import logging

from .extractor import VideoFrameExtractor
from .selector import FrameSelector

logger = logging.getLogger(__name__)


class VideoPreprocessor:
    """
    Main entry point for video-to-images conversion.

    Usage:
        preprocessor = VideoPreprocessor()
        result = preprocessor.process(
            video_path="/path/to/video.mp4",
            output_dir="/path/to/frames/",
            target_frames=30,
        )
        # result["image_dir"] → 可直接传给 Pipeline.run()
    """

    def __init__(
        self,
        target_frames: int = 30,
        blur_threshold: float = 100.0,
        similarity_threshold: float = 0.92,
        min_interval_seconds: float = 0.3,
    ):
        self.target_frames = target_frames
        self.extractor = VideoFrameExtractor(strategy="target_count")
        self.selector = FrameSelector(
            blur_threshold=blur_threshold,
            similarity_threshold=similarity_threshold,
            min_interval_seconds=min_interval_seconds,
        )

    def process(
        self,
        video_path: str,
        output_dir: str,
        progress_callback: callable = None,
    ) -> dict:
        """
        Run full video preprocessing pipeline.

        Args:
            video_path: Path to video file.
            output_dir: Directory for extracted frames.
            progress_callback: Optional callback(stage, percent).

        Returns:
            dict with:
              - "image_dir":       Path to directory of selected frames.
              - "total_extracted": Number of frames initially extracted.
              - "total_selected":  Number of frames after filtering.
              - "frame_names":     List of selected frame filenames.
              - "video_info":      Dict with fps, duration, total_frames.
              - "warnings":        List of warning strings.
        """
```

**编排流程**：

```
process(video_path, output_dir):
  1. 验证:
     - 检查 video_path 是否存在
     - 检查 output_dir 是否可写

  2. 提取 (Extract):
     raw_frames = extractor.extract(
         video_path,
         output_dir=raw_dir,   # 先输出到临时目录
         target_frames=target_frames * 3,  # 提取目标量3倍供筛选
     )
     → progress_callback("extract", 30)

  3. 筛选 (Select):
     selected_frames = selector.select(raw_frames)
     → progress_callback("select", 70)

  4. 后处理:
     - 将 selected_frames 复制/移动到 output_dir
     - 重命名为统一格式: frame_0001.jpg, frame_0002.jpg, ...
     - 清理临时目录
     → progress_callback("complete", 100)

  5. 返回结果
```

**为什么 extract 时取 target_frames × 3**：
- 给筛选器留足够的"废片"可以丢弃
- 如果视频本身帧数少（如仅90帧），×3仍然取得到
- extractor 的 min_interval_frames=3 保证下限，不会因×3就全取

**与 Pipeline 的无缝对接**：

```python
# 在 tasks.py 中的调用方式：
preprocessor = VideoPreprocessor(target_frames=30)
video_result = preprocessor.process(video_path, output_image_dir)

# 直接将 image_dir 传给现有 Pipeline，零改动
pipeline_result = pipeline.run(
    image_dir=video_result["image_dir"],   # ← 完全兼容
    quality=quality,
    progress_callback=pipeline_progress_cb,
)
```

```python
@app.route("/api/tasks", methods=["POST"])
def create_task():
    """Upload images OR a single video file, start reconstruction."""

    # 优先检查是否视频模式
    video_file = request.files.get("video")
    image_files = request.files.getlist("images")

    quality = request.form.get("quality", "high")
    mode = request.form.get("mode", "colmap")       # 重建模式: colmap/mvs
    input_type = request.form.get("input_type", "images")  # 新增: images/video

    task_id = str(uuid.uuid4())
    task = Task(id=task_id, status="uploading", num_images=0)
    db.session.add(task)
    db.session.commit()

    image_dir = os.path.join(UPLOAD_FOLDER, task_id)
    os.makedirs(image_dir, exist_ok=True)

    if input_type == "video" and video_file and _allowed_video(video_file.filename):
        # ── 视频路径 ──
        video_filename = video_file.filename.rsplit("/", 1)[-1].rsplit("\\", 1)[-1]
        video_path = os.path.join(image_dir, video_filename)
        video_file.save(video_path)

        task.num_images = 0  # 切片后才知道具体帧数
        task.stage = "video_processing"
        db.session.commit()

        from tasks import run_reconstruction_async
        run_reconstruction_async(
            task_id, image_dir, quality, mode,
            video_path=video_path,    # ← 传入视频路径
        )

    elif input_type == "images":
        # ── 图像路径（原有逻辑不变）──
        valid_files = [f for f in image_files if f.filename and _allowed_image(f.filename)]
        if not valid_files:
            return jsonify({"error": "No valid files"}), 400

        task.num_images = len(valid_files)
        db.session.commit()

        for f in valid_files:
            filename = f.filename.rsplit("/", 1)[-1].rsplit("\\", 1)[-1]
            f.save(os.path.join(image_dir, filename))

        from tasks import run_reconstruction_async
        run_reconstruction_async(task_id, image_dir, quality, mode)

    else:
        return jsonify({"error": "Provide 'images' for image mode or 'video' for video mode"}), 400

    return jsonify({"task": task.to_dict()}), 202
```

**关键设计**：不创建新的API端点，复用 `POST /api/tasks`，通过 `input_type` 字段区分。好处：
- 前端只需在一个接口上切换
- task管理逻辑完全复用
- 后续扩展（如 "scan" 模式、"depth_camera" 模式）也是新增 input_type 即可
